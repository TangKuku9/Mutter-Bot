# 管理面板设计基线

面板采用「稳序控制台」框架。入口是运行概览，导航按工作区、机器人配置和系统分组。路由、API、实时订阅和配置保存流程沿用原有实现。

## 字号与间距

| 元素 | 规范 |
| --- | --- |
| 页面标题 | 桌面 26px，手机 24px |
| 卡片标题 | 16px，手机 15px |
| 正文、表单、常规表格 | 14px |
| 小尺寸表格、表头、次要信息 | 13px |
| 注释、时间、标签 | 12px |
| 手机可编辑输入 | 16px，避免移动浏览器自动放大 |
| 桌面页面边距 | 32px，中屏 24px，手机 16px |
| 卡片内边距 | 常规 22px，紧凑与手机 16px |
| 卡片圆角 | 12px |

紧凑模式缩小菜单、表格行与卡片间距，不降低文字字号。宽表在组件内部横向滚动，不拉宽整个页面；手机状态描述表切为单列。

## 外观与品牌

- 中性色、页面背景、卡片与边框统一使用 `styles/panel.css` 的 `--panel-*` 变量。
- 用户设置继续存储在 `mutter-panel-settings`，保留主题色、深色模式与紧凑模式。新增原生颜色选择器，允许指定任意六位十六进制颜色。
- `panelTheme.js` 保留用户原色作为 `--el-color-primary`；正文强调、浅底选中态和按钮文字分别使用派生变量。不要把原色直接用于小字号文字。
- `--panel-accent-text` 在页面、卡片、次级底色及选中背景上至少达到 4.5:1 的对比度。主按钮常态、悬停和按下状态分别配对前景色。
- Element Plus 组件按需加载，覆盖样式需要足够的选择器优先级，避免加载新页面后恢复为原始主题色文字。
- 成功、警告、危险与信息色保持独立语义，同时生成深浅主题下的色阶和按钮前景色。
- Logo 使用现有矢量资产，并按深浅色切换。产品标志保持品牌原色；界面交互色遵循用户设置。

## 页面与状态

- `panelNavigation.js` 统一维护导航分组、页面名称与描述；`router.js` 维护对应的懒加载组件。
- `PanelNavigation.vue` 同时用于桌面侧栏和手机抽屉。900px 以下使用抽屉，路由成功后关闭；未保存修改阻止导航时，抽屉保留。
- 概览首页统计、任务、服务状态均来自原有 API。首次读取失败显示占位与错误提示；后续更新失败保留上一次数据并标记过期。
- 模型耗时只代表成功模型调用，不包含排队、图片准备和发送；没有成功样本时明确显示无样本。
- 任务过程按需读取，失败时提供可见的重试反馈；模型请求与运行诊断保留独立入口。

## 验证

```powershell
npm --prefix web test
npm --prefix web run build
dotnet build Mutter.sln --no-restore
dotnet run --project tools/ProactiveCheck --no-build -- --logic-only
```

本地浏览器验证使用合成 API 数据，不连接 QQ 或付费模型：覆盖全部 10 个页面在 1440、1024、390、320px 下的常规与深色紧凑模式，并检查主题持久化、导航保护、错误状态、任务详情与键盘跳转。

主题检查包含 7 个预设与白、黑、黄自定义色，在深浅模式下检查主按钮和描边按钮的常态、悬停、按下，以及链接、标签和选中导航。验证脚本、报告与截图保存在本地忽略目录 `artifacts/panel-framework/`。
