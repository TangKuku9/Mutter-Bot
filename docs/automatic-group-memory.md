# 自动群记忆

入口为管理面板「机器人配置 → 群记忆」。选择一个已有群，配置学习条件和独立总结服务商/模型，再开启自动学习并保存。原有人工摘要继续在「群管理」中维护，两类记忆分别保存。

## 旧生产环境升级

- 自动学习默认关闭。启动升级只补齐两张小表及索引，不读取历史正文、不生成历史摘要、不发起记忆模型请求。
- 首次开启时，在保存设置的同一事务中记录该群当前最新消息位置。已有数万条记录也不会成为待总结队列。
- 关闭后重新开启会重新建立起点，暂停期间的记录不会回灌。切换群记录范围或群启用状态也会更新边界，使在途旧结果失效。
- 正常重启保留已启用群的处理游标、日配额及退避状态，只继续处理启用后尚未处理的新记录。异常或损坏的配置按关闭处理，缺失有效游标时先建立新起点。
- 定时任务不补跑过去错过的时刻。到点没有新增记录时跳过，不调用模型。

初次升级需要创建 `(GroupId, Id)` 索引，成本随现有消息数量增长，但不会逐条调用 AI。更新前按原有方式备份 SQLite；回退旧程序时保留新表和索引即可，无需删除数据。

## 学习条件

三种条件分别启停，可以同时生效，任一满足即可触发。同一群只有一个记忆任务；多个条件同时命中或多个定时落在同一时刻，会合并为一次学习，并在运行记录中显示触发理由。

| 条件 | 范围与含义 |
| --- | --- |
| 新增记录 | 1–1000 条，从上次处理位置统计本群允许保存的人类消息 |
| 时间间隔 | 1–10080 分钟，距上次完成处理达到时长，且有新增记录 |
| 定时任务 | 最多 4 个时刻，支持每天、工作日、每周，按北京时间运行 |

首次开启以开启时间作为间隔起点。只有到达批次完成或明确跳过的边界才推进游标；一批最多处理 40 条，超出输入预算时进一步缩小。积压超过 24 小时的消息不用于长期学习，避免持续追赶陈旧闲聊。

只学习已落库的人类消息：仅 @ 模式使用被 @ 的消息，围观并记录模式可以使用该群已保存的消息。纯内存观察窗口、Bot 回复和私聊均不会成为群记忆来源。

## 总结模型

每个群独立保存总结连接和模型，不更改日常聊天配置。复用「AI 设置 → 管理服务商」的连接库，可以从目录选择或直接填写模型 ID；连接上的密钥、协议、请求头和模型窗口信息继续复用。

未选总结连接、连接失效或调用失败时，聊天继续运行，不自动改用聊天模型。引用中的连接不能删除；目录内正在被记忆配置使用的模型不能被移除。手填目录外的模型不阻止无关的连接编辑。

每批最多一次实际 HTTP 请求，不自动修复输出或进行额外格式探测。采用 30 秒期限，不联网、不看图、不携带聊天人设，调用用途记为 `group_memory`。后台模型需要能够按提示输出 JSON。

批大小按所选模型的真实输入窗口动态收缩；模型窗口过小、连接不存在等本地可判定的问题会直接暂停并记录原因，不发起请求、不消耗当日配额，也不占用“连续 3 次失败”的重试额度。身份字段使用批内短句柄（`u1`、`u2`），时间使用北京时间。昵称缺失或回退为 openid 时以批内称呼代替，保留正常昵称；旧记忆中的显示前缀和已知成员 ID 也会在发送模型前处理。本地原始身份和历史记忆不改写，用户自行写在消息正文里的标识符不属于身份字段脱敏范围。

## 容量与成本

- 每群最多 128 条有效短记忆，单条最多 120 个 Unicode 字符。
- 一次最多新增、修改或删除 5 项，每项引用新增消息中的原文证据；不复制整段历史正文到记忆表。
- 个人记忆在句柄解析后仍校验每条来源的作者：新增、替换和删除均只能使用本人的消息，不能借用同批其他成员的句柄或混合他人的来源。
- 单群每天最多 12 次、全局每天最多 48 次学习请求，失败和发包前预留也计入。北京时间换日，重启、清空及重新启用都不能重置当日配额。全局 48 次是硬上限：群很多时平均到每群的学习频率会下降，这是控制成本的预期行为。
- 调用失败会退避；同一游标连续失败 3 次后记录跳过，防止一直为同一批坏输入付费。连接缺失、模型窗口不足等本地失败不会进入这 3 次重试，也不推进游标。
- 全局最多一个记忆学习任务，复用后台执行槽，并使用独立任务键，避免排在普通群回复的同会话队列前面。已开始的 HTTP 仍占用一个槽。

成员自述和固定事实默认 90 天失效；临时事件按明确结束日期失效，没有日期时最多 7 天。正文含“明天/后天/今晚/下周/下周末/具体月日”等一次性时间的事实也按 7 天处理；模型把事件标成 `fact` 但给了 `eventEndAt` 时，服务端仍按事件处理。事件日期最长不超过来源时间后 30 天。

## 回复与管理

普通回复和主动接话共用本地召回，最多选择 4 条相关记忆，整体不超过 600 个现有文本预算单位。该选择不调用模型。普通回复的自动资料放在对话最前面，最终预算不足时先移除；主动判定在附图和提示预算确定后决定是否带入自动资料。

召回有最低相关门槛：正文至少命中两个相邻双字、一个 2 字以上的精确标签，或短 query 的一个有效命中；只有常见时间词、虚词或“曾提到/自述”这类前缀不会触发注入。普通回复以当前消息和同批合并输入作为查询；只有“还是老时间吗”“几点开始”等明确的短追问，才补充最近十分钟内的两条人类消息，仍受当前回合的时间/行边界约束。切换到计算、知识问答等完整的新问题时，不继续携带上一轮话题。

普通回复的运行留痕在系统词、图片和检索内容齐备并完成最终输入预算裁剪后记录条数、字符数和条目 ID。预算移除自动资料时记录为 0 条，并标明已被预算剔除；前置看图等未携带记忆的请求不生成这条记录。

原有普通回复全局、主动发言全局与群级记忆注入权限继续生效。本页的“自动学习”开关只控制新增学习；“群记忆”页不提供独立的自动注入开关，是否注入仍看「AI 设置」与「群管理」的记忆注入权限。关闭自动学习只停止新增学习，已有条目仍可按注入权限使用；关闭注入不删除记忆。私聊不读取群记忆。

中文召回使用本地相邻双字、英文词/数字及短标签，允许零命中。同义改写和隐晦指代仍可能漏召回，当前不引入向量模型或额外数据库。

面板可以查看条目、来源和最近 10 次运行，逐条删除或清空自动记忆。清空会同时推进学习边界并拒绝在途旧补丁，避免刚清空又被写回；单条删除也会让在途补丁失效。原有人工摘要不受此操作影响。源聊天被删除后显示来源不可用，不为追溯额外复制正文。
